Web Development Learning Path

A structured curriculum to master web development fundamentals

0% Complete

01

HTML Fundamentals

Learn the structure and semantics of web pages

  • Learn what HTML stands for and its purpose in web development
  • Understand the basic HTML document structure: <!DOCTYPE html>, <html>, <head>, <body>
  • Study the difference between HTML elements, tags, and attributes
  • Practice creating your first HTML file and opening it in a browser
  • Learn about HTML comments and their importance
Resources: MDN HTML Basics, W3Schools HTML Tutorial
  • Master heading tags: <h1> through <h6> and their semantic hierarchy
  • Learn paragraph tags: <p> and line breaks: <br>
  • Understand text formatting: <strong>, <em>, <mark>, <small>
  • Practice creating a simple text-based page with proper heading structure
  • Learn about HTML entities for special characters (&, <, >, ©)
Resources: MDN Text Content, HTML Entities Reference
  • Create ordered lists: <ol> and unordered lists: <ul>
  • Learn list items: <li> and nested lists
  • Master anchor tags: <a> with href attribute
  • Understand different link types: external, internal, anchor links, email links
  • Practice creating navigation menus using lists and links
  • Learn about relative vs absolute URLs
Resources: MDN Links, HTML Lists Guide
  • Add images using <img> tag with src, alt, width, height attributes
  • Understand the importance of alt text for accessibility
  • Learn about image formats: JPEG, PNG, SVG, WebP and when to use each
  • Embed videos: <video> and audio: <audio> elements
  • Practice creating a gallery page with multiple images
  • Learn about responsive images with srcset attribute
Resources: MDN Images, HTML5 Media Elements
  • Create forms using <form> element with action and method attributes
  • Learn input types: text, email, password, number, date, checkbox, radio, submit
  • Understand form structure: <label>, <input>, <textarea>, <select>, <button>
  • Practice creating a contact form with validation attributes (required, pattern, min, max)
  • Learn about form accessibility: proper label associations, fieldset, legend
  • Understand GET vs POST methods
Resources: MDN Forms, HTML5 Form Validation
  • Learn semantic elements: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>
  • Understand when to use <div> vs semantic elements
  • Learn about <figure> and <figcaption> for images
  • Practice converting a non-semantic page to semantic HTML5
  • Understand the benefits of semantic HTML for SEO and accessibility
  • Learn about HTML5 document outline algorithm
Resources: MDN HTML5 Semantic Elements, HTML5 Doctor
  • Create tables: <table>, <thead>, <tbody>, <tfoot>
  • Learn table elements: <tr>, <th>, <td>
  • Understand table attributes: colspan, rowspan for merging cells
  • Practice creating a pricing table or data table
  • Learn about table accessibility: scope attribute, captions
  • Understand when to use tables vs CSS Grid/Flexbox for layout
Resources: MDN HTML Tables, Accessible Tables Guide
  • Learn HTML validation using W3C Validator
  • Understand proper indentation and code organization
  • Learn about HTML5 doctype and meta tags (charset, viewport, description)
  • Practice writing clean, readable, maintainable HTML
  • Understand accessibility basics: ARIA labels, semantic HTML, alt text
  • Learn about HTML5 features: data attributes, microdata
  • Build a complete multi-page website using all HTML concepts learned
Resources: W3C Validator, HTML Best Practices Guide
02

CSS Fundamentals

Style and design beautiful, responsive web pages

  • Understand what CSS is and how it works with HTML
  • Learn three ways to add CSS: inline, internal (style tag), external stylesheet
  • Master CSS selectors: element, class (.), ID (#), attribute selectors
  • Learn about specificity and the cascade
  • Practice writing CSS rules: selector { property: value; }
  • Understand CSS comments and organization
Resources: MDN CSS Basics, CSS Selectors Reference
  • Learn color values: named colors, hex (#), rgb(), rgba(), hsl(), hsla()
  • Master typography: font-family, font-size, font-weight, font-style, line-height
  • Understand text properties: color, text-align, text-decoration, text-transform, letter-spacing
  • Learn about Google Fonts and web fonts (@font-face)
  • Practice creating a typography system with consistent font sizes and spacing
  • Understand font fallbacks and font stacks
Resources: MDN Typography, Google Fonts, CSS Color Values
  • Understand the CSS box model: content, padding, border, margin
  • Learn about box-sizing: content-box vs border-box
  • Master margin and padding: shorthand notation, individual sides
  • Understand width and height: fixed (px), relative (%, em, rem), viewport units (vw, vh)
  • Learn about min-width, max-width, min-height, max-height
  • Practice creating layouts with proper spacing and sizing
  • Understand collapsing margins
Resources: MDN Box Model, CSS Units Guide
  • Learn display values: block, inline, inline-block, none, flex, grid
  • Master CSS positioning: static, relative, absolute, fixed, sticky
  • Understand z-index and stacking context
  • Learn about float and clear (legacy, but good to know)
  • Practice creating layouts with different positioning techniques
  • Understand when to use each positioning method
Resources: MDN Display, CSS Positioning Guide
  • Learn flexbox container properties: display: flex, flex-direction, flex-wrap, justify-content, align-items, gap
  • Master flex item properties: flex-grow, flex-shrink, flex-basis, align-self, order
  • Understand the main axis and cross axis
  • Practice creating navigation bars, card layouts, and centered content with flexbox
  • Learn about flexbox vs float for layouts
  • Build a responsive navigation menu using flexbox
Resources: CSS-Tricks Flexbox Guide, Flexbox Froggy Game
  • Learn grid container: display: grid, grid-template-columns, grid-template-rows, gap
  • Master grid item placement: grid-column, grid-row, grid-area
  • Understand grid template areas for named layouts
  • Learn about fr units, repeat(), minmax(), auto-fit, auto-fill
  • Practice creating complex layouts: magazine-style, dashboard, card grids
  • Understand when to use Grid vs Flexbox
  • Build a responsive grid-based layout
Resources: CSS-Tricks Grid Guide, Grid Garden Game
  • Understand responsive design principles: mobile-first vs desktop-first
  • Learn viewport meta tag and its importance
  • Master media queries: @media (max-width), @media (min-width)
  • Learn about breakpoints: mobile (320px), tablet (768px), desktop (1024px+)
  • Practice making a website responsive with media queries
  • Understand fluid typography: clamp(), min(), max()
  • Learn about responsive images: srcset, sizes attribute
Resources: MDN Responsive Design, Media Queries Guide
  • Learn pseudo-classes: :hover, :focus, :active, :visited, :nth-child(), :first-child, :last-child
  • Master pseudo-elements: ::before, ::after, ::first-line, ::first-letter
  • Understand CSS transitions: transition-property, transition-duration, transition-timing-function, transition-delay
  • Learn about CSS transforms: translate(), rotate(), scale(), skew()
  • Practice creating interactive buttons and hover effects
  • Build animated elements using transitions and transforms
Resources: MDN Pseudo-classes, CSS Transitions Guide
  • Learn CSS custom properties (variables): --variable-name: value; var(--variable-name)
  • Understand CSS architecture: BEM methodology, component-based CSS
  • Learn about CSS preprocessors: Sass/SCSS basics (variables, nesting, mixins)
  • Practice organizing CSS: reset/normalize, variables, base styles, components, utilities
  • Understand CSS specificity and how to avoid conflicts
  • Learn about CSS methodologies: OOCSS, SMACSS, BEM
  • Build a complete styled website with organized, maintainable CSS
Resources: MDN CSS Variables, BEM Methodology, Sass Basics
03

JavaScript Fundamentals

Add interactivity and dynamic behavior to websites

  • Understand what JavaScript is and its role in web development
  • Learn how to add JavaScript to HTML: inline, internal script tag, external .js file
  • Master variables: var, let, const and when to use each
  • Learn about data types: number, string, boolean, undefined, null, object, symbol
  • Understand type coercion and typeof operator
  • Practice writing your first JavaScript: console.log(), alert(), prompt()
Resources: MDN JavaScript Guide, JavaScript.info Variables
  • Learn arithmetic operators: +, -, *, /, %, ** (exponentiation)
  • Master comparison operators: ==, ===, !=, !==, <, >, <=, >=
  • Understand logical operators: &&, ||, !
  • Learn assignment operators: =, +=, -=, *=, /=
  • Understand operator precedence and parentheses
  • Practice writing expressions and calculations
Resources: MDN Expressions and Operators
  • Master if/else statements and conditional logic
  • Learn switch statements for multiple conditions
  • Understand ternary operator: condition ? value1 : value2
  • Practice creating decision-making programs
  • Learn about truthy and falsy values
  • Build a simple calculator or decision tree
Resources: MDN Control Flow, JavaScript.info Conditionals
  • Learn for loops: for (initialization; condition; increment)
  • Master while and do-while loops
  • Understand for...in and for...of loops
  • Learn about break and continue statements
  • Practice iterating over arrays and objects
  • Build programs that process lists of data
Resources: MDN Loops and Iteration
  • Learn function declarations: function name() { }
  • Master function expressions and arrow functions: () => { }
  • Understand parameters and arguments
  • Learn about return statements and function return values
  • Understand scope: global scope, function scope, block scope
  • Learn about hoisting and function hoisting
  • Practice writing reusable functions
Resources: MDN Functions, JavaScript.info Functions
  • Learn array creation: [], new Array(), array literals
  • Master array methods: push(), pop(), shift(), unshift(), splice(), slice()
  • Understand array iteration: forEach(), map(), filter(), reduce(), find(), findIndex()
  • Learn about array methods: includes(), indexOf(), join(), sort(), reverse()
  • Practice manipulating arrays: adding, removing, searching, transforming
  • Build programs that work with lists of data
Resources: MDN Arrays, Array Methods Guide
  • Learn object creation: {}, new Object(), object literals
  • Master accessing properties: dot notation, bracket notation
  • Understand object methods and 'this' keyword
  • Learn about Object.keys(), Object.values(), Object.entries()
  • Practice creating and manipulating objects
  • Understand JSON: JSON.stringify(), JSON.parse()
  • Build programs that work with structured data
Resources: MDN Objects, JavaScript.info Objects
  • Understand the Document Object Model (DOM)
  • Learn selecting elements: getElementById(), querySelector(), querySelectorAll(), getElementsByClassName()
  • Master modifying content: textContent, innerHTML, innerText
  • Learn about modifying attributes: setAttribute(), getAttribute(), classList
  • Understand creating elements: createElement(), appendChild(), insertBefore()
  • Practice dynamically updating page content
  • Build interactive features: show/hide, add/remove elements
Resources: MDN DOM Manipulation, JavaScript.info DOM
  • Learn event listeners: addEventListener(), removeEventListener()
  • Master common events: click, submit, change, input, focus, blur, keydown, keyup
  • Understand event object: event.target, event.preventDefault(), event.stopPropagation()
  • Learn about event delegation
  • Practice creating interactive forms and buttons
  • Build features: modals, dropdowns, accordions, tabs
  • Understand event bubbling and capturing
Resources: MDN Events, JavaScript.info Events
  • Understand asynchronous JavaScript and why it's needed
  • Learn about callbacks and callback hell
  • Master Promises: new Promise(), .then(), .catch(), .finally()
  • Learn async/await syntax: async function, await keyword
  • Understand fetch() API for making HTTP requests
  • Practice fetching data from APIs
  • Learn about error handling: try/catch blocks
Resources: MDN Promises, JavaScript.info Async/Await, Fetch API Guide

Resources: WordPress Media Library Guide, Image Optimization Best Practices

05

Git & Version Control

Track changes and collaborate on code projects

  • Understand what version control is and why it's essential
  • Learn about Git vs GitHub: Git is the tool, GitHub is the hosting service
  • Understand the benefits: track changes, collaborate, backup, rollback
  • Learn about repositories: local vs remote
  • Install Git on your computer
  • Configure Git: git config --global user.name, git config --global user.email
Resources: Git Documentation, GitHub Guides
  • Initialize repository: git init
  • Check status: git status
  • Stage files: git add . (all files) or git add filename
  • Commit changes: git commit -m "message"
  • View commit history: git log
  • Practice creating your first repository and making commits
  • Understand the three states: working directory, staging area, repository
Resources: Git Basics Tutorial, Git Cheat Sheet
  • Create a GitHub account
  • Create a new repository on GitHub
  • Connect local repository to remote: git remote add origin URL
  • Push to GitHub: git push -u origin main (or master)
  • Clone a repository: git clone URL
  • Pull changes: git pull
  • Practice syncing local and remote repositories
Resources: GitHub Documentation, GitHub Hello World Guide
  • Understand what branches are and why they're useful
  • Create a branch: git branch branchname or git checkout -b branchname
  • Switch branches: git checkout branchname or git switch branchname
  • List branches: git branch
  • Merge branches: git merge branchname
  • Delete branches: git branch -d branchname
  • Practice creating feature branches and merging them
Resources: Git Branching Guide, GitHub Flow
  • Understand what .gitignore is and why it's important
  • Create .gitignore file: node_modules/, .env, *.log, etc.
  • Learn common patterns: /folder/, *.extension, !exception
  • Understand commit message best practices: clear, descriptive, present tense
  • Learn about README.md files and their importance
  • Practice creating a proper project structure with .gitignore and README
  • Understand when to commit: logical units of work, not too often, not too rarely
Resources: .gitignore Templates, Git Best Practices

Responsive Design & Mobile-First

Create websites that work beautifully on all devices

  • Understand why mobile-first design matters (mobile traffic statistics)
  • Learn mobile-first vs desktop-first approach
  • Understand viewport meta tag: width=device-width, initial-scale=1
  • Learn about common breakpoints: 320px (mobile), 768px (tablet), 1024px (desktop)
  • Practice designing for mobile screens first
  • Understand touch targets: minimum 44x44px for buttons
Resources: Mobile-First Design Guide, Responsive Design Principles
  • Use relative units: %, em, rem, vw, vh instead of fixed px
  • Learn about max-width for containers: max-width: 1200px; margin: 0 auto;
  • Master fluid typography: clamp(), min(), max() functions
  • Practice creating flexible layouts that adapt to screen size
  • Understand rem vs em: rem is relative to root, em is relative to parent
  • Learn about container queries (new CSS feature)
Resources: Fluid Typography Guide, CSS Units Best Practices
  • Master media query syntax: @media (min-width: 768px) { }
  • Learn about media types: screen, print, all
  • Understand media features: width, height, orientation, resolution
  • Practice writing complex media queries with multiple conditions
  • Learn about mobile-first media queries: min-width approach
  • Understand when to use max-width vs min-width
Resources: MDN Media Queries, Responsive Breakpoints Guide
  • Learn srcset attribute for responsive images
  • Understand sizes attribute for responsive images
  • Master picture element: <picture> with <source> and <img>
  • Learn about art direction: different images for different screen sizes
  • Practice implementing responsive images
  • Understand responsive videos: aspect-ratio, object-fit
Resources: MDN Responsive Images, Picture Element Guide
  • Use browser DevTools for responsive testing
  • Learn about device emulation in Chrome DevTools
  • Test on real devices: iOS, Android phones and tablets
  • Use online tools: BrowserStack, Responsive Design Checker
  • Practice debugging layout issues on different screen sizes
  • Understand common responsive design problems and solutions
Resources: Chrome DevTools Guide, Responsive Testing Tools
