Chapter 4

Development Roadmap & Learning Path

Your week-by-week learning plan: WordPress basics, building your agency site, taking on first clients, and scaling systems. This is the practical guide for going from "junior dev" to "running a real agency" in your first 12 weeks.

Phase 1: Foundation (Weeks 1–2)

Goal: Get your development environment set up and build your first basic WordPress site.

Week 1: Setup & WordPress Basics. Days 1–2: Environment setup — install Node.js (LTS version), install Cursor IDE, set up Claude Code in Cursor, install LocalWP (local WordPress environment), create GitHub account plus install Git, install Chrome plus DevTools familiarization. Days 3–5: WordPress fundamentals — create first local WordPress site in LocalWP, install Astra theme (free), install Elementor (free), practice building a simple 3-page site (Home, About, Contact), add contact form with WPForms, learn Pages vs Posts, Media Library, Menus. Days 6–7: Portfolio project #1 — build your first portfolio piece (fictional client), business type: local contractor (plumber, electrician, etc.), 3 pages: Home, Services, Contact, use free stock photos (Unsplash), make it look professional (good enough to show).

Week 2: WordPress Intermediate + First Real Project. Days 8–10: Essential plugins and SEO — install Rank Math SEO plugin, learn meta titles, descriptions, sitemaps, install Wordfence (security), install UpdraftPlus (backups), practice optimizing portfolio project #1 for SEO. Days 11–12: Portfolio project #2 — build second portfolio piece (fictional), business type: restaurant or cafe, 5 pages: Home, Menu, About, Gallery, Contact, add Google Maps embed, make it mobile-responsive. Days 13–14: Discounted real project #1 — find your first real client (friend/family), offer $200–300 for 3-page site, in exchange: testimonial plus portfolio permission, build it using what you've learned, ask Claude Code for help when stuck.

Phase 2: Your Agency Website (Weeks 3–6)

Goal: Build your professional agency website using Next.js (your portfolio piece plus learning modern tech).

Week 3: Next.js Basics. Days 15–17: Next.js crash course — watch Next.js tutorial (YouTube, 2–3 hours), read Next.js docs (quick start guide), create simple Next.js app with Cursor plus Claude Code, build basic landing page (Home page), deploy: push to GitHub, connect Vercel. Days 18–21: Agency site structure — plan sitemap for your agency site (Home, About, Services, Portfolio, Contact), design: sketch wireframes (Figma or paper), build homepage with hero, services preview, CTA, style: add Tailwind CSS classes, test: make sure it's responsive.

Week 4–5: Complete Agency Site. Days 22–26: Service and portfolio pages — build services page (list your 3 packages), build portfolio page (grid of your 2–3 projects), build individual case study pages, add contact form (using Resend API), test: all links work, forms submit. Days 27–31: Content and polish — write homepage copy (with Claude's help), write about page (your story, why you're different), write service descriptions, add SEO meta tags (titles, descriptions), add Google Analytics, final polish: fix any bugs, improve mobile view. Days 32–35: Launch your site — buy domain (yourname.ca or vairedigital.ca), connect domain to Vercel, test: everything works on live domain, set up business email (Google Workspace or free Zoho), submit sitemap to Google Search Console.

Week 6: Portfolio Building. Days 36–42: Discounted projects #2 and #3 — find 2 more real clients (aim for $300–400 each), build sites using WordPress plus your templates, goal: get testimonials plus portfolio pieces, document: screenshot process for case studies, add these projects to your portfolio page.

Phase 3: Client Work & Systems (Weeks 7–10)

Goal: Start taking on full-price clients and systemize your workflow.

Week 7–8: First Full-Price Projects. Partner starts pitching with your portfolio. Take on 1–2 Starter Package clients ($1,200 each). Use templates and checklists from this guide. Track time spent per task (learn your actual speed). Refine your project workflow based on learnings. Request testimonials and referrals.

Week 9–10: System Optimization. Create project templates (folder structure, checklists). Document common tasks (how-to guides for yourself). Set up Trello board for project management. Build email templates for all client communications. Create reusable WordPress site templates. Automate anything repetitive (backup schedules, etc.).

Phase 4: Scale & Grow (Weeks 11–12+)

Goal: Take on more clients, add retainer services, optimize profitability.

Week 11–12: Retainer Setup. Identify clients who might need maintenance. Pitch maintenance packages to past clients. Set up monthly processes (updates, backups, reports). Automate as much as possible (MainWP for multi-site management). Upsell SEO services to existing clients.

Ongoing Growth: Aim for 3–5 projects per month. Build 5–8 retainer clients by Month 6. Systemize: templated workflows for speed. Learn new skills as needed (e.g., e-commerce if demand exists). Delegate: consider hiring contractor for overflow work (Month 6+).

Learning Resources

WordPress: WP Beginner (free tutorials), YouTube "WordPress for Beginners" (various channels), official WordPress documentation.

Next.js: Next.js official docs (excellent), YouTube "Next.js 14 Crash Course" (2–3 hour videos), Frontend Masters (paid, but high quality).

Tailwind CSS: Tailwind official docs (best resource), Tailwind UI (paid components, optional), YouTube "Tailwind CSS Crash Course".

SEO: Moz Beginner's Guide to SEO (free), Ahrefs YouTube channel (free tutorials), Backlinko blog (Brian Dean).

Business/Sales: "The Mom Test" (book, how to talk to customers), Y Combinator Startup School (free online course), "Obviously Awesome" (book, positioning).

When You Get Stuck: Claude Code in Cursor (ask it anything), ChatGPT (free tier), Stack Overflow (Google your error message), WordPress support forums, Reddit: r/webdev, r/wordpress.
